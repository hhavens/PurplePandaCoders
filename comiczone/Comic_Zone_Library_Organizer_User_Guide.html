Library Organizer

Comic Zone User Guide — Automatically rename and arrange your comic files using their metadata.

1. Open Library Organizer

Open Settings, then choose Library Organizer in the sidebar. Configure the options and click Save to keep your preferences.

2. Move files or Copy files

OptionWhat happens
Move filesMoves original files to their new paths. Comic Zone updates the stored library paths.
Copy filesCreates copies at the destination and keeps the originals in place.

For your first organization run, consider copying a small selection to verify the folder and filename patterns before moving your collection.

3. Set the Base Folder

  1. Click Browse… next to Base Folder.
  2. Choose the destination directory, such as /Volumes/PlexMediaServer/Comics.
  3. Confirm the green Folder exists status. An orange Folder not found message indicates that the path is unavailable.

Generated folders are placed under this base folder. Make sure the drive or network volume is mounted and writable before organizing.

4. Configure File Organization

Check Use file organization to rename comic files from metadata. Enter a pattern in the text field.

{series}[ v{volume}][ {number:000}]

Example result: Batman v2026 113.cbz. The file extension is retained from the source. The Preview updates as you edit the pattern, using a sample Batman comic.

5. Configure Folder Organization

Check Use folder organization to create subfolders from metadata. For example:

{publisher}/{imprint}/{series}[ ({volume} {format?})]

With the sample metadata, the resulting hierarchy is:

Comics/
└── DC Comics/
    └── DC Black Label/
        └── Batman (2026 Comic)/
            └── Batman v2026 113.cbz

File and folder organization can be enabled independently or together. When folder organization is disabled, files are placed directly in the base folder.

6. Available Naming Tokens

TokenMeaningExample
{series}SeriesBatman
{number}Issue number113
{volume}Volume2026
{title}Issue titleThe Dark Knight
{publisher}PublisherDC Comics
{imprint}ImprintDC Black Label
{year}Year2026
{month}Month8
{day}Day15
{writer}WriterTom King
{format}FormatComic
{ageRating}Age ratingMA

Padding issue numbers

{number:000} turns issue 4 into 004. The number of zeroes controls the minimum width.

Text transforms

Use |upper, |lower, or |sanitize on tokens to change case or sanitize text. For example, {series|upper} produces BATMAN.

Conditional blocks and optional tokens

Wrap a segment in square brackets to omit the entire segment when a required token is empty:

{series}[ v{volume}][ {number:000}]

Add ? to a token within a block to omit just that token if empty, while allowing the rest of the block to remain:

{series}[ ({volume} {format?})]

This can produce Batman (2026 TPB), Batman (2026), or Batman, depending on which fields are populated.

7. Run the Organizer

  1. Save your settings.
  2. Select the comics you want to organize in the library, then invoke the Library Organizer action.
  3. Review the confirmation dialog, which shows the destination and sample target paths.
  4. Click Move or Copy to proceed, or Cancel to stop before changes are made.

The organizer skips files already at their intended paths. If neither file nor folder organization is enabled, it displays Nothing to Do.

8. Handle Duplicate Filenames

If a file already exists at the destination, Comic Zone displays a Duplicate Found dialog. You can choose:

ChoiceEffect
Move/Copy and ReplaceReplace the existing destination file with the source.
Don't Move/CopySkip the source file and leave the destination unchanged.
Move/Copy, but keep both filesRename the incoming file with a numbered suffix, such as Batman (1).cbz.
Cancel AllStop processing the remaining conflicting files.

Check Do this for all to apply your selected conflict resolution to subsequent duplicates. Non-conflicting files are processed first, so Cancel All does not undo work already completed.

9. Review the Results

When organization finishes, a summary shows counts for successful operations, skipped files, and failures. Choose Yes to open the detailed Library Organizer Report.

The report includes the action, source path, and outcome message for each processed file. Click Save… to export a tab-separated .tsv report, or OK to close it.

10. Tips and Troubleshooting

  • Missing metadata: Fill in relevant fields in Comic Info Editor before organizing so filenames and folder names are meaningful.
  • Network storage: Check that the destination drive is connected and writable.
  • No files moved: Check that at least one organization checkbox is enabled, the base folder is set, and the selected files need changes.
  • Duplicate warning: Compare the source and destination carefully before choosing Replace.
  • Test safely: Back up important files and use Copy files for an initial trial.
