Smart Lists

Create dynamic library views that automatically include comics matching the rules you define — from simple publisher filters to detailed reading orders made from hundreds of rule groups.

1. What Smart Lists Are

A Smart List is a dynamic list of comics selected by rules instead of by manually adding individual files. Comic Zone evaluates the rules against the metadata in your library and shows the comics that match.

Smart Lists are useful for publisher collections, unread comics, missing metadata, formats, specific series, reading orders, and highly customized collections.

Smart Lists stay dynamic. When comic metadata changes, a comic can automatically enter or leave a Smart List depending on whether it still matches the rules.

2. Creating a Smart List

Use the Smart List control in the sidebar toolbar to create a new Smart List. The toolbar also contains controls for other sidebar/library actions.

The New Smart List window asks for a name and starts with a rule group.

Enter a descriptive name, choose whether the Smart List should match Any or All groups, then expand the group to build its rules.

Click Create when the Smart List is ready. Cancel closes the editor without creating it.

3. Understanding Groups and Rules

Smart Lists use two levels of logic: groups and rules inside each group.

A rule has three basic parts: a metadata field, an operator, and — when required — a value.

Example rule
Publisher contains Marvel

The + control inside a group adds another rule. The − controls remove rules or groups. Add Group creates another independent group.

Groups can be collapsed to make large Smart Lists easier to navigate. When collapsed, Comic Zone summarizes the group's conditions in a compact row.

4. Any vs. All

There are two places where you can choose matching behavior.

At the top of the Smart List

Match Any of the following groups means a comic can match any one group and be included. Match All means it must satisfy every group.

Inside a group

All of the following rules requires every rule in that group to match. Choosing Any allows any rule in that group to qualify the comic.

Example: one exact comic
Series equals Thor: Son of Asgard
Volume equals 2004
Number equals 1

Set the group to All because all three values identify the intended comic.

5. Choosing a Metadata Field

The first menu in a rule selects which comic metadata field Comic Zone should examine. The available fields are listed alphabetically for easier navigation.

Available fields include items such as B/W, Colorist, Cover Artist, Day, File Path, Format, Genre, Imprint, Inker, Language, Letterer, Manga, Modified Info, Month, Notes, Number, Opened, Penciller, Publisher, Read %, Series, Series Has Gap, Summary, Tags, Title, Volume, Writer, and Year.

The best field depends on what you are organizing. For example, use Format to distinguish collected editions, Read % for reading status, and Series / Volume / Number together when identifying exact comics.

6. Choosing an Operator

The second menu determines how Comic Zone compares the selected field with your value. The operators shown depend on the type of field being evaluated.

OperatorUse
containsThe field contains the entered text.
equalsThe field matches the value.
starts withThe field begins with the entered text.
ends withThe field ends with the entered text.
is emptyThe field has no value. No comparison text is needed.
is not emptyThe field contains a value.
>The value is greater than the entered value.
<The value is less than the entered value.
is in the rangeThe value falls within the specified range.

Boolean or multi-value fields can offer additional operators appropriate to that field, such as true/false or multi-value matching choices.

8. Building Reading Orders with Smart Lists

Smart Lists can also represent a specific reading order. Each group can identify one comic using several rules, while the Smart List itself is set to match Any group.

In the example, a group identifies an exact comic with:

Series equals Thor: Son of Asgard
Volume equals 2004
Number equals 1

The next groups identify #2, #3, #4, and so on. Each group uses All rules, while the Smart List uses Any groups. This means a comic is included when it matches any one complete reading-order entry.

Why groups matter: without groups, a long reading order containing many series and issue numbers could accidentally combine unrelated values. Keeping Series + Volume + Number together in an All group preserves each exact comic identity.

9. Smart Lists, Folders, and the Sidebar

Smart Lists can be organized beneath folders. This is useful for large projects such as master reading orders.

A folder can contain multiple Smart Lists, allowing a large collection to be split into manageable sections such as Part 1 and later ranges. Selecting the folder provides a combined view based on the Smart Lists contained beneath it.

The colored count badges provide quick list/count information directly in the sidebar.

11. Sort by Query Order

Sort by Query Order is especially useful for reading-order Smart Lists. Instead of treating the Smart List as only a filter, Comic Zone can use the sequence of its query groups to determine the order in which matching comics are displayed.

For example, if group 1 identifies one comic, group 2 identifies the next, and group 3 identifies the third, query-order sorting keeps those matches in that same intended sequence.

When maintaining a reading order, keep the groups in the desired reading sequence. Changing the query order can change the displayed reading order when Sort by Query Order is enabled.

12. Editing an Existing Smart List

Choose Edit Smart List… from the context menu. The editor displays the existing name, top-level Any/All selection, and all saved groups and rules.

Expand a group to edit its individual conditions. Collapse groups you are not working on to make large queries easier to navigate. Click Save to apply your changes or Cancel to leave the Smart List unchanged.

13. Automatic Updates

Smart Lists are based on comic metadata, so membership can change when that metadata changes. For example, if a Smart List searches for missing Format values and Comic Scraper later fills in Format, that comic may automatically leave the list.

The same behavior makes Smart Lists useful for cleanup tasks: create a list describing the metadata problem, fix the comics, and watch matching items disappear as they no longer meet the rule.

14. Troubleshooting

A comic appears that I did not expect

Check whether the group is set to Any when it should be All. With Any, only one rule in the group needs to match.

A TPB appears in my issue list

If regular issues have an empty Format field, add Format is empty to the same All group as your issue rule. This excludes entries whose Format contains TPB or another value.

A comic I expect is missing

Inspect the comic's actual metadata and compare it with every rule in the group. Exact equals rules are more restrictive than contains.

A reading order is in the wrong sequence

Verify the group order and use Sort by Query Order. Each exact comic should normally have its own All-rules group.

A large Smart List is difficult to edit

Collapse completed groups and expand only the group currently being edited. This keeps long reading-order queries manageable.
